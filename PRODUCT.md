# FlowDL — Product Context

## Product Truth
FlowDL is a precision, minimal desktop wrapper for `yt-dlp` on Linux. It bridges the command-line power of yt-dlp and ffmpeg with an authentic, responsive native desktop user experience built with Go and Wails.

## Audience & Scene
Linux developers, power users, designers, and video editors who use yt-dlp regularly to archive footage, download reference audio, or fetch streams. They run it on high-DPI monitors under dark desktop environments (GNOME, KDE, tiling window managers). They expect immediate responsiveness, dense information readability, zero lag, and zero web-marketing bloat.

## Mode
**Operate**: The user is executing a focused task (fetching media from the web). The tool should disappear into the workflow. Efficiency, clarity, legible transfer states, and quick keyboard-driven execution outrank decorative expression.
